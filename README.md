# Ingeniería Web — Semana 3

Actividad en clase del quinto ciclo de la UTPL.

## Contenido

- `index.html`: maquetación básica con encabezado y menú de navegación.
- `secundarias/mision.html`: página de misión.
- `requerimientos.html`: levantamiento de requisitos de Netplus convertido a HTML básico.
- `img/logo.svg`: logo sencillo de HTML.

## Servidor local

Esta carpeta se encuentra en `Week/Third/workshop` dentro del espacio de trabajo de la materia. El archivo `compose.yaml` compartido está en la raíz `WE`.

Desde esa raíz, ejecutar:

```powershell
docker compose up -d
```

Abrir <http://localhost:8080/Week/Third/workshop/>.

Los archivos también pueden servirse desde cualquier servidor de archivos estáticos conservando sus rutas relativas.
